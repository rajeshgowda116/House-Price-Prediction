For columns like:

But because you have many categorical columns, use a Scikit-learn Pipeline + OneHotEncoder rather than manually using pd.get_dummies().

This is especially important because your FastAPI input must go through exactly the same preprocessing as your training data.

Step 20 — Build preprocessing pipeline

Example:

from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline

Separate:

numeric_features = [
    "Floor_Number",
    "Bathroom",
    "Balcony",
    "Carpet_Area_sqft",
    "Super_Area_sqft"
]


categorical_features = [
    "location",
    "Status",
    "Transaction",
    "Furnishing",
    "facing",
    "overlooking",
    "Car Parking",
    "Ownership"
]

Then create preprocessing:

numeric_pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="median"))
])


categorical_pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="most_frequent")),
    ("encoder", OneHotEncoder(
        handle_unknown="ignore"
    ))
])

And:

preprocessor = ColumnTransformer([
    (
        "num",
        numeric_pipeline,
        numeric_features
    ),
    (
        "cat",
        categorical_pipeline,
        categorical_features
    )
])
